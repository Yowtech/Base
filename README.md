About

Base adalah project yang dikembangkan dengan pendekatan sederhana, modular, dan mudah dikembangkan.

Fokus utama project ini adalah:

- Simple & clean
- Modern interface
- Lightweight
- Easy to customize
- Struktur yang mudah dikembangkan
- Tampilan dengan visual yang smooth dan minimal

Installation

Clone repository:

git clone https://github.com/yowtech/base.git
cd base

Install dependencies:

npm install

Run project:

npm start

Customization

Bagian HTML dapat disesuaikan melalui:

index.html

Sedangkan tampilan visual dapat diatur melalui:

style.css

Contoh warna utama:

:root {
    --background: #F8F7FA;
    --surface: #FFFFFF;
    --primary: #C8B6E8;
    --secondary: #D8CFE8;
    --text: #35333A;
    --muted: #85818C;
}
